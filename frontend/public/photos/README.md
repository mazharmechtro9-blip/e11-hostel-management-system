# Preview imagery

These are explicitly labelled visual placeholders, not photographs of E-11 Hostel.
Replace them using Owner → Public website → Edit details: the homepage photo URL
and five HTTPS room photo URLs (2 through 6 seater). Empty values restore these placeholders.
No remote photo is fetched by the backend; browser image rendering is used.

- `building.png`: AI-generated architectural concept, created for this project.
- `room-2.jpg`, `room-3.jpg`, `room-5.jpg`: photographic placeholders from
  https://github.com/technext/royal/tree/master/image (`room1.jpg`, `room2.jpg`, `room4.jpg`),
  the Colorlib Royal template. Original template: https://colorlib.com/wp/template/royal/.
- `room-4.jpg`: photographic placeholder from the same Golden Hotel template below, `images/portfolio/04.jpg`.
- `room-6.jpg`: photographic placeholder from
  https://github.com/learning-zone/website-templates/blob/master/golden-hotel-free-html5-bootstrap-web-template/images/banner/2.jpg.

These stock interiors illustrate visual direction; they do not establish actual
room capacity, layout or amenities. Inventory and prices come from the API.
Inter is self-hosted under the SIL Open Font License in `../fonts/OFL.txt`.
